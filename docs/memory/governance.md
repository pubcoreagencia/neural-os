# Memory Governance

## Regras

- Nenhum conhecimento deve ser sobrescrito sem versionamento.
- Toda entrada precisa de origem rastreável.
- Toda busca precisa retornar contexto com provenance.
- Cada item deve carregar domínio, entidade e permissões.

## Visibilidade

- `PUBLIC`
- `INTERNAL`
- `CONFIDENTIAL`
- `RESTRICTED`
