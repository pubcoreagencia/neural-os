# Neural OS

Site institucional premium para posicionar o Neural OS como o sistema operacional da empresa.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Direção

O site vende uma nova forma de administrar empresas. A linguagem pública evita jargão técnico e traduz o produto em valor executivo: memória institucional, decisões rastreáveis, processos vivos e governança.

## Estrutura

- `app/`: rotas, SEO e layout global.
- `components/`: experiência principal, motion runtime, botão magnético e visualização 3D.
- `docs/`: blueprint de UX, copywriting, design system e motion.
- `lib/`: utilitários compartilhados.
